数据源与设置

扫描本地 JSONL，支持查看和删除会话。修改目录可使用启动参数。

收藏、归档与会话索引保存在服务的 .data 目录。归档只调整显示状态；永久删除会移除对应 JSONL 文件，无法撤销。

永久删除会话？

将直接删除以下 JSONL 文件，并清理 ASH 中的收藏、归档和索引。此操作无法撤销，不会放入回收站。

请先结束该会话的 CLI 进程；如果仍在运行，文件可能重新生成。需要保留内容时，请先导出。
